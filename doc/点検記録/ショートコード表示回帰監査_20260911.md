削除済みの未公開ショートコードは今回の表示監査の対象外。

最初のコミット `68dccf2` と現在のHTML・読み込み履歴を比較し、初期実装が参照する
外部 `common.css` / `bootstrap-add.css` の使用クラスを照合した。
外部ファイルそのものはGit管理されていないため、2026-09-11の取得内容を参照しており、
初期コミット当日の配信内容と完全に一致するとは断定しない。

| 確認 | 結果 |
| --- | --- |
| WordPress 7.1 / PHP 8.3.33、Twenty Twenty-Five、Welcart有効 | 実HTTPで14種類を描画 |
| Chromium、Playwright 1.55.0 | 320 / 390 / 575 / 576 / 767 / 768 / 991 / 992 / 1440px、全9幅成功 |
| WebKit、Playwright 1.55.0 | 同じ9幅で成功。Safari製品版・実機確認の代替とはしない |
| 修正前CSSを応答へ差し替え | カード画像・行数省略・タグ装飾・ホバー欠落を再現して失敗 |
| PHP 7.4 / 8.3構文 | 変更PHPとfixtureで成功 |
| WPCS | 変更PHPとテストで成功。お知らせ03は既存のlegacy除外も外したルールで成功 |

ブラウザでは実際に公開した検証ページのショートコードを使い、画像のみ縦長・横長・正方形へ
差し替えた。代替画像、長い日本語/空白なし英数字、画像枠、行数省略、列数、セル・画面の
横はみ出し、ホバー、コンソールエラー、プラグイン外へのCSS漏れを確認した。
LP内の入れ子カード、親カテゴリ属性の省略/明示、存在しないデータも検証した。
外部資産へのリクエストは遮断している。

マトリクスはプラグイン有効化、ショートコード回帰、梱包回帰・統合、バックアップ回帰を含む。
6.0.3 / 7.0.3ではブラウザ確認を行っていない。稼働環境の7.1と混同しない。
SWELLは未導入のため未確認。Chrome/Edge製品版、Safari、iPhone Safari、Android Chrome実機は未確認。
お知らせ03の4列構造と商品一覧02の行間は初期実装のまま維持する。

## 再実行

ローカルWordPressとWelcartが起動した状態で、リポジトリルートから実行する。
新しいテスト基盤は追加せず、既存のPlaywright 1.55.0 Dockerイメージを利用する。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/test-shortcode-layout.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tests/test-shortcode-layout.ps1 -Engine webkit
```

テストは一時ページ、6商品、LP、カテゴリ・タグを作成し、成功・失敗いずれでも `finally` で削除する。
既存の `year/order/area` カテゴリは再利用し、削除しない。レポートとPC/スマホ幅の画像は
Git管理外の `dist/shortcode-layout-chromium/` または `dist/shortcode-layout-webkit/` へ保存する。
実HTTPテストはローカル専用。通常のWordPress CIマトリクスにはPHP回帰テストが含まれる。
既存の検証ページが残っている場合は、共有する一時カテゴリの清掃が干渉しないよう作成を停止する。
ChromiumとWebKitは順番に実行する。

プロセス強制終了などで清掃されなかった場合は、出力された検証ページIDに対して
`php /tmp/shortcode-layout-fixture.php delete ページID` をwebコンテナ内で実行する。
専用メタデータを持つ検証ページだけを削除できる。

利用者によるDB初期化やボリューム再作成は不要。反映確認ではページを再読み込みする。
