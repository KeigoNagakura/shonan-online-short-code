# 商品リスト03のデザイン回帰修正

> 文書整理日: 2026-09-27。既存本文を保持し、日本語名・分類・参照リンクを整理。ファイル名の日付は本文の作成・実施日を優先し、不明なものは整理日とした。 以下は移設前の監査記録であり、現環境での再検証結果ではない。

## 原因と比較基準

最初のコミット `68dccf2e12f022d88b057fc252b45c9c762e4557` の
`wc_item_list03.php` / `wc_item_card03.php` と現在のHTMLを比較した。
2列・768px以上3列の構造と画像・タイトルのクラスは維持されている。
`a060af3df74dbb5f45c5671750504d6d587e2d72` で外部CSSの読み込みが削除されたが、
`img_frame1_1`、`frame_over`、`frame_max_hover20`、`opacity-hover6`、
`multi_line_truncate_of_2` の代替定義が同梱されていなかった。

初期コミットが参照する `https://api.shonan-online.com/css/common.css` を
2026-09-11に取得し、画像枠、中央配置、2行省略、ホバーの定義を確認した。
外部CSS自体はGitに保存されていないため、取得内容が初期コミット当日の配信内容と
完全一致するかは確認できない。現在取得できる参照CSSを使った比較でも5画面幅の検証を通過した。

必要な定義を `css/short-code.css` のカード03配下へ限定して追加した。
画像は幅・高さを100%とした `object-fit: cover` で縦横比を維持し、
長い連続文字もカード幅に収める。HTML構造、商品取得、リンク、価格の処理は維持する。
CSSキャッシュ値だけを更新した。プラグインのリリースバージョンは変更しない。

## 検証結果（2026-09-11）

- 稼働環境: WordPress 7.1 / PHP 8.3.33、Twenty Twenty-Five、Welcart有効。
  基準資料のWordPress 7.0.3とは異なる。
- 実際のWordPressの商品取得とショートコード関数で6商品分のHTMLを生成。
  テスト商品・カテゴリはDBトランザクションをロールバックして撤去。
- Chromium / Playwright 1.55.0: 1440、768、767、390、320px。
  外部資産を遮断し、3列/2列、画像枠の正方形、縦長・横長・正方形・代替画像、
  長い商品名の2行省略、ホバー拡大/透明度、横スクロール不在、コンソールエラー不在を確認。
- 修正前CSSでは1440pxで画像枠が幅215px・高さ400px、タイトルが120px・省略なしとなり失敗。
  修正後は画像215×215px、タイトル40px・2行省略となり成功。
- 変更PHP（キャッシュ定数、検証用fixture）のPHP 7.4/8.3構文検査とWPCSは成功。
- 作業中のwebログに新しいPHP Warning / Notice / Fatal / Parse errorなし。
- 一時管理者で管理画面ログインとプラグイン設定画面のHTTP 200を確認。
  READMEのデモ資格情報ではログインできなかったため、一時管理者を使用して検証後に削除した。
  一時ページも削除し、検証用商品がDBに残っていないことを確認した。

SWELL、Chrome/Edgeの製品版、Safari、iPhone Safari、Android Chromeの実機、
WordPress 6.0.3 / 7.0.3での実行確認は未実施。
本記録はカード03・リスト03の最初の修正時点の結果。続く追加監査で他のカード・一覧・タグも
修正・検証した。共通CSSへの変更と拡大した確認範囲は [ショートコード表示監査](ショートコード表示回帰監査_20260911.md) を参照。
DB初期化やボリューム再作成は不要。

## 再現方法

ローカル開発専用。Welcartと開発プラグインを有効にして実行する。

1. 一時ページに `[sosc_wc_item_list03 slug="sosc-layout-verification"]` を掲載する。
   このページで通常のショートコード用CSS読み込みを確認する。
2. `tests/wc-item-list03-fixture.php` をwebコンテナの `/tmp/` へコピーし、
   `php /tmp/wc-item-list03-fixture.php > /tmp/rendered.html` で実行する。
   出力HTMLをホストのGit管理外のディレクトリ（例: `dist/wc-list03-check/`）へコピーする。
3. 既存の `mcr.microsoft.com/playwright:v1.55.0-noble` イメージをwebコンテナと
   同じネットワークで起動し、Playwright 1.55.0を一時ディレクトリへインストールする。
4. `SOSC_LIST03_URL` に一時ページのURL、`SOSC_LIST03_HTML` に生成HTMLのパスを設定し、
   `node wc-item-list03-browser.js` を実行する。スクリプトも一時ディレクトリへコピーする。
   通常のテーマ表示内へ検証HTMLを挿入し、テスト画像を差し替えて計測する。
5. 任意で `SOSC_LIST03_SCREENSHOTS` に既存の出力ディレクトリを指定できる。
   `SOSC_LIST03_CSS` に修正前CSSを指定すると失敗を再現できる。
   さらに `SOSC_LIST03_REFERENCE` に取得した旧外部CSSを指定すると参照表示を比較できる。
6. 終了後、一時ページを削除する。生成HTML・画像・外部CSSはコミットしない。
