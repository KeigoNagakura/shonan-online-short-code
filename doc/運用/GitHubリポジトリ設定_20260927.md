以下は旧リポジトリで当時検討した設定です。現行の公開リポジトリの設定項目や必須チェックとして扱わないでください。

## 1. CI成功をマージ条件にする

`.github/workflows/ci.yml` をGitHubへpushし、CIを最低1回実行した後に設定します。GitHubは一度も実行されていないチェックを必須チェックとして選択できません。

リポジトリの `Settings` → `Rules` → `Rulesets` で `main` を対象にし、必須ステータスチェックとして次を指定します。

- `PHP syntax (7.4 and 8.3)`
- `WordPress Coding Standards`
- `Plugin metadata`
- `Docker Compose configuration`

ほかのブランチ保護項目は、今回の指定には含めません。

## 2. マージ済みブランチを自動削除する

リポジトリの `Settings` → `General` → `Pull Requests` にある `Automatically delete head branches` を有効にします。

この設定はPull Requestをマージした後、GitHub上の作業ブランチを自動削除します。ローカルブランチは自動削除されません。
