## 推奨構成

GitHub Releaseを配布物の原本とし、GitHub Actionsから `sosys.shonan-online.com` へ更新JSONとZIPを自動配置する構成を推奨します。

これにより、タグ、ソース、配布ZIPの対応関係をGitHubに残しつつ、既存の独自更新機能が参照するURLも維持できます。本番サーバーへの認証情報はGitHub Actions Secretsへ保存し、リポジトリには含めません。

## 選択肢

| 方式 | 特徴 | 向いている場合 |
| --- | --- | --- |
| 現在のサーバーへ手動配置 | 単純だが、配置漏れや版違いが起きやすい | リリース頻度が低い初期運用 |
| GitHub ActionsからSSH/SFTP/rsyncで自動配置 | タグ作成を起点にZIPとJSONを同時公開できる | `sosys.shonan-online.com` を継続利用する場合 |
| GitHub Releasesから直接配布 | サーバー管理が少なく履歴が明確 | 更新処理がGitHub URLとリダイレクトに対応できる場合 |
| オブジェクトストレージ/CDN | 高可用・高速でサーバー負荷が低い | 配布量が増えた場合 |
| WordPress.org公式ディレクトリ | WordPress標準更新を利用できるが、審査と公開規約がある | 一般公開プラグインとして配布する場合 |

次回 `3.9.0` では更新ホストを `sosys.shonan-online.com` に切り替える予定です。旧版からの更新を保つため、旧ホストへのJSONとZIPの配布も必要です。旧ホストの廃止条件は [更新配信サーバー移行](更新配信サーバー移行_20260927.md) に従います。実装手順は[Git連動プラグイン更新配布](Git連動プラグイン更新配布_20261110.md)を参照してください。
