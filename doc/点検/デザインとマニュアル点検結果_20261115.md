# デザインとマニュアル点検結果

- 作成日: 2026-11-15
- 版: 第1版
- 最終更新日: 2026-11-15
- 対象: `wp-plugin` のローカル公開画面、管理画面、同梱マニュアル

## 結論

確認した固定サンプルと管理画面に、プラグイン由来の確定したデザイン崩れやマニュアル不備は見つからなかった。修正は0件。画像比較の差分は下記のとおり個別に確認した。実行時に作成したfixtureは清掃し、残存0件を確認した。

## 実施と差分の判定

| 対象 | 方法・結果 |
| --- | --- |
| 環境 | `osaru-wp` の3コンテナが稼働。WordPress 7.1.3、SWELL 2.15.0、so-short-code 3.8.5、Welcart 2.12.5を基準画像の環境条件へ照合 |
| 公開画面 | 15ショートコードを320・390・768・1280pxで撮影。横はみ出し0。部品画像は差分0。1280pxのページ全体画像2枚に差分があり、目視ではサイドバーのアーカイブ・カテゴリ位置に限られ、プラグイン部品の崩れは確認されなかった |
| 管理画面 | 3タブを320・390・1280pxで撮影。横はみ出し0。1280pxの3枚に各85画素の差分。差分座標は上部バーと左メニューで、プラグイン領域外。基準Chrome 157.0.8103.39に対し現行157.0.8103.79 |
| 同梱マニュアル | 29章すべてを320・390・1280pxで開いた。画像欠落・横はみ出し0。目次カードと代表6章の配置、コピー操作、存在しない章への案内、バックアップ案内を検査し成功 |
| 設定画像 | 8枚を現行の設定画面から再撮影し、同梱画像とのSHA-256が8枚すべて一致 |
| 後片付け | 所有印付きfixtureを清掃し、`posts=0 terms=0 skus=0`を確認。コンテナ内の一時コピーも削除 |

差分のあるページ全体画像を無条件に一致と扱わず、部品画像と差分位置を別に確認した。今回の固定サンプルは、月次バックアップタブの保存先識別子と箱詰め受注画面の注文情報を画像基準へ含めない。
