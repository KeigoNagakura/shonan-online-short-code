# 現行ローカル検証手順

- 作成日: 2026-11-15
- 版: 第2版
- 最終更新日: 2026-11-15
- 対象: `wp-plugin` の現行ローカル開発環境

## 基本確認

プロジェクトの[Docker開発環境](../運用/Docker開発環境_20260927.md)と[プログラムAgent](../../AGENTS.md)を前提とする。Docker Desktop起動後、既存Composeプロジェクトを確認し、対象のローカル環境を起動済みにしてから、プロジェクトルートで次を実行する。

```powershell
& C:/osaruAi/shell/WordPress開発環境_20260927.ps1 -ProjectRoot C:/osaruAi/project/wp-plugin -Mode Verify
```

`Verify`はDB接続、必要なPHP拡張、固定プラグイン、ショートコード登録、保存先、URL、HTTPSログイン、管理画面を確認する。機能固有の変更は下記の該当試験も実施する。既存DBとボリュームを削除・再投入しない。

## 変更別の確認対象

| 変更範囲 | 現行資材 | 確認条件 |
| --- | --- | --- |
| GitHub Release版判定・ZIP生成 | [版判定テスト](../../tests/test_next_github_release.py)、[更新契約試験](../../tests/github-release-update.php)、[Releaseワークフロー](../../.github/workflows/plugin-update-release.yml) | Pythonテスト、PHP契約試験、ワークフローの対象ファイルと配布判定を確認する。外部公開はこの検証に含めない |
| 箱詰め送料・注文 | [SKU試験](../../tests/packing-sku-batch.php)、[注文登録試験](../../tests/packing-order-registration.php)、[購入経路試験](../../tests/packing-checkout-flow.php)、[保守試験](../../tests/packing-maintenance-guards.php) | 試験のローカル限定ガードとfixture清掃・DBロールバック条件を確認してから実行する |

| 帳票 | [帳票fixture](../../tests/documents-fixture.php)、[PDF検査](../../tests/verify-pdf-text.py)、[帳票説明](../../src/so-short-code/documents/README.md) | ダミー注文、PDF出力先、清掃方法を確認する |
| 表示・管理画面 | [正規デザインキャプチャ](../../tests/visual-baseline/README.md)、[撮影器](../../tests/visual/capture.cjs)、[管理画面撮影器](../../tests/visual/admin-capture.cjs) | 対応する基準画像と実ブラウザ画像を比較する |
| Cron・自動更新設定 | [読取り診断](../../tests/runtime-schedule-check.php) | ローカルではCronと自動更新の停止状態を確認する |

Release版判定のPython回帰試験は、プロジェクトルートで次を実行する。2026-11-15のローカル再確認では8件が成功した。

```powershell
python -m unittest discover -s tests -p test_next_github_release.py
```

`tests/`のPHPファイルにはWordPressを読み込むものと単独実行できるものがある。実行前に各ファイル冒頭と終了処理を確認し、WordPress依存の試験を単独PHPとして実行しない。変更箇所に対応する試験が現配置にない場合は、その機能の合格を推測せず、必要な試験を用意する。
