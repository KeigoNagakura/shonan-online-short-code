# 湘南オンラインプラグイン 機能仕様

> 文書整理日: 2026-09-27。既存本文を保持し、日本語名・分類・参照リンクを整理。ファイル名の日付は本文の作成・実施日を優先し、不明なものは整理日とした。

> 第2版。最終更新日: 2026-11-10。店頭受け取りの画面仕様を更新。

## 1. この文書の目的

この文書は、WordPressプラグイン `ShonanOnlineShortCode` の現在の実装機能を、保守・検証時に確認できるよう整理したものです。

利用方法と操作上の仕様は [利用者仕様](プラグイン利用者仕様_20260927.md)、処理・データ・依存関係の詳細は [技術仕様](プラグイン技術仕様_20260927.md) を参照してください。

対象はバージョン `3.8.5` です。管理画面の表示だけではなく、`src/so-short-code/` の読込経路、PHP、JavaScript、CSS、更新処理を基準にしています。

実装ファイルが存在していても、プラグインから読み込まれていない機能は「現在無効な実装」として区別します。

## 2. 機能構成

現在有効な主な機能は次のとおりです。

| 分類 | 内容 |
| --- | --- |
| 一般ショートコード | 8個 |
| Welcart用ショートコード | 7個 |
| 管理画面設定 | 7項目 |
| テーマ・フォーム調整 | SWELL、フォーム表示調整 |
| データ保存 | 独自設定テーブル |
| 更新 | 独自更新サーバーによる更新通知・詳細表示 |

## 3. 一般ショートコード

### 3.1 お知らせリスト01

```text
[sosc_info_list01 slug="カテゴリスラッグ" list="6" addClass="追加クラス"]
```

指定カテゴリの投稿を新しい順に表示します。

- 表示内容は投稿日と投稿タイトル
- 日付形式は `YYYY/MM/DD`
- `list` の既定値は5件
- 各投稿へのリンクを表示
- `addClass` で外側の要素へCSSクラスを追加

### 3.2 お知らせリスト02

```text
[sosc_info_list02 slug="カテゴリスラッグ" list="6" addClass="追加クラス"]
```

指定カテゴリの投稿を和暦年度付きで表示します。

- 表示内容は和暦年度と投稿タイトル
- 西暦を令和、平成、昭和、大正、明治へ変換
- 新しい投稿順
- `list` の既定値は5件

### 3.3 お知らせリスト03

```text
[sosc_info_list03 slug="カテゴリスラッグ" list="6" orderSlug="order" yearSlug="year" areaSlug="area" addClass="追加クラス"]
```

投稿を「発注元」「内容」「エリア」「年度」の4列で表示します。投稿に設定された子カテゴリを各列の値として使用します。

| 属性 | 内容 | 既定値 |
| --- | --- | --- |
| `slug` | 一覧対象のカテゴリスラッグ | 必須 |
| `list` | 表示件数 | `5` |
| `orderSlug` | 発注元カテゴリの親スラッグ | `order` |
| `yearSlug` | 年度カテゴリの親スラッグ | `year` |
| `areaSlug` | エリアカテゴリの親スラッグ | `area` |
| `addClass` | 追加CSSクラス | なし |

### 3.4 お知らせリスト04

```text
[sosc_info_list04 slug="カテゴリスラッグ" list="6" addClass="追加クラス"]
```

指定カテゴリの投稿をブログカードのグリッドで表示します。各項目は内部で `sosc_blog_card01` を使用します。

- 大画面は3列、小さい画面では2列または1列
- アイキャッチ、タイトル、抜粋、更新日を表示
- アイキャッチがない場合は共通のNo Image画像を表示
- `list` の既定値は5件

### 3.5 お知らせリスト05

```text
[sosc_info_list05 slug="カテゴリスラッグ" list="6" addClass="追加クラス"]
```

指定カテゴリの投稿を罫線付きの一覧で表示します。

- 表示内容は投稿日と投稿タイトル
- 新しい投稿順
- `list` の既定値は5件

### 3.6 タグ表示01

```text
[sosc_tag_view01 tag="タグ名1,タグ名2" addClass="追加クラス"]
```

指定したタグをリンク付きバッジとして表示します。

- `tag` はカンマ区切りで複数指定可能
- タグ名は完全一致で判定
- 各タグのアーカイブページへリンク

### 3.7 ブログカード01

```text
[sosc_blog_card01 slug="投稿スラッグ" link="リンク先" addClass="追加クラス"]
```

指定投稿を1枚のブログカードとして表示します。

- アイキャッチ画像
- 投稿タイトル
- 抜粋、またはHTMLを除去した本文の先頭1000文字
- 更新日
- `link` で指定したリンク先
- アイキャッチがない場合は共通のNo Image画像

リンク先は投稿URLから自動取得せず、`link` 属性の値を使用します。

### 3.8 LP内容の共通表示

```text
[sosc_target_content slug="LPスラッグ"]
```

カスタム投稿タイプ `lp` の公開済み投稿をスラッグで取得し、本文を別ページへ埋め込みます。複数ページで共通コンテンツを利用するための機能です。

通常本文と同じ `the_content` フィルターを通して本文を出力します。

## 4. Welcart用ショートコード

Welcartの商品投稿とSKUテーブルを参照するため、Welcartが必要です。

### 4.1 商品カード01

```text
[sosc_wc_item_card01 post_name="商品スラッグ" addClass="追加クラス"]
```

横長の商品カードを表示します。

- 商品画像
- 商品名
- 商品本文
- SKUの最低価格と最高価格
- 商品ページへのリンク

### 4.2 商品カード02

```text
[sosc_wc_item_card02 post_name="商品スラッグ" addClass="追加クラス"]
```

正方形画像を使用する縦型商品カードです。商品名と最低価格から最高価格までを表示します。

### 4.3 商品カード03

```text
[sosc_wc_item_card03 post_name="商品スラッグ" addClass="追加クラス"]
```

簡易な縦型商品カードです。商品画像、商品名、SKU最低価格を表示します。

### 4.4 商品リスト01

```text
[sosc_wc_item_list01 slug="カテゴリスラッグ" list="6" addClass="追加クラス"]
```

指定カテゴリの商品を商品カード01で縦1列に表示します。

- `list` の既定値は5件

### 4.5 商品リスト02

```text
[sosc_wc_item_list02 slug="カテゴリスラッグ" list="6" addClass="追加クラス"]
```

指定カテゴリの商品を商品カード02で表示します。小さい画面では2列、中画面以上では3列です。

- `list` の既定値は5件

### 4.6 商品リスト03

```text
[sosc_wc_item_list03 slug="カテゴリスラッグ" list="6" addClass="追加クラス"]
```

指定カテゴリの商品を商品カード03で表示します。小さい画面では2列、中画面以上では3列です。

- `list` の既定値は5件

### 4.7 請求書・領収書

Welcartが有効な場合だけ `[sosc_wc_documents]` を登録します。固定ページに配置すると、注文時のメールアドレスと注文確認メールの注文番号からPDFを取得するフォームを表示します。ログイン不要です。請求書はキャンセル・見積り以外、領収書はさらに入金済みの注文が対象です。Welcartの注文データは変更しません。掲載ページはHTTPSを使用し、キャッシュ対象外にしてください。試行制限・対応範囲は [帳票機能の説明](../../src/so-short-code/documents/README.md) を参照してください。

## 5. 管理画面

WordPress管理メニューへ「湘南オンラインプラグイン」を追加します。利用には `manage_options` 権限が必要です。

画面には次のタブがあります。

- ショートコード
- Welcart用ショートコード
- その他
- 月次バックアップ（月次バックアップ有効時だけ、利用・保存・復元方法と実行結果を表示）

「その他」の設定保存では権限とnonceを確認します。

### 月次バックアップ

- 初期状態は無効で、「その他」の利用チェックから有効化する
- サイト設定のタイムゾーンで毎月末日午前3時に単発WP-Cronを予約し、完了後に次回分を予約する
- 手動バックアップ、最終実行結果、次回予定、バックアップ一覧、管理者用ダウンロードを提供する
- WordPressファイル、DB全テーブル・ビュー・トリガー・ルーチン・イベント、`backup-info.json`、手動復元手順をZIPへ格納する
- InnoDBを同一時点の整合性スナップショットで取得し、非InnoDBテーブルがある場合は作成しない
- バックアップ中だけWordPressをメンテナンス状態にし、別のメンテナンス処理が進行中なら開始せず、プラグインが作成したメンテナンスファイルだけを終了時に削除する
- `wp-content/sosc-backups/`内のランダムな非公開サブディレクトリへ、PHP実行停止ガード付きの`.zip.php`として保存し、直接アクセス防止ファイルも配置する
- 保存ディレクトリは最初の手動または自動バックアップ実行時に作成し、WordPress直下や`wp-content`直下の既存`.htaccess`は変更しない
- バックアップ保存先、キャッシュ、一時ファイル、ログ、代表的な他バックアップ保存先は除外する
- 対象ファイル、DB、SQL膨張、一時SQL、作成中ZIP、保護変換中のZIP二重化、処理余裕、最低100MBの安全余裕を含め、空き容量が下回る場合は作成しない
- 多重実行をロックし、正常に完成したZIPだけを6世代保持する
- 利用チェックを有効にしたときだけ暗号化パスワード欄を表示し、表示・非表示ボタンを提供する
- 利用チェックを有効にした場合だけ「月次バックアップ」結果タブを表示し、一覧、実行結果、次回予定、手動実行、ダウンロードを同タブへまとめる
- 利用チェック操作時に一時ZIPの暗号化・再読込テスト結果を反映し、AES-256非対応環境では暗号化パスワード欄を表示しない
- パスワードがある場合は実行時のZIP生成・再読込テストでAES-256対応を判定し、対応環境では全エントリを暗号化する
- パスワードがある状態でAES-256を利用できない場合は、平文ZIPを作らずバックアップを中止する
- パスワードがない場合は暗号化なしのZIPを作成する
- 入力パスワードはWordPress認証ソルト由来の鍵でAES-256-GCM暗号化してDBへ保存し、バックアップ実行時だけ復号する
- バックアップ内の`database.sql`から暗号化パスワード設定行を除外し、暗号化なしZIPへ復号材料を含めない
- 月末処理の開始前に再試行を予約し、通常エラーとPHP強制終了のどちらでも1日後に最大3回再試行する
- 復元、管理画面からの削除、外部転送は提供しない

### 5.1 H1タグ非表示

機能を有効にし、WordPressメニュー `none_h1` に対象ページを登録します。現在URLと登録URLが一致したページではbodyへ `none_h1` クラスを追加し、H1を非表示にします。

### 5.2 コンテンツ上マージン非表示

WordPressメニュー `none_contents_top_margin` に登録したページで、bodyへ `none_contents_tm` クラスを追加します。

### 5.3 コンテンツ下マージン非表示

WordPressメニュー `none_contents_bottom_margin` に登録したページで、bodyへ `none_contents_bm` クラスを追加します。

### 5.4 フォント指定

次の選択肢があります。

- 変更しない（内部値 `default`）
- 明朝体（端末のシステムフォント）

既存設定との互換性のため設定値 `noto-serif-jp` は維持し、Google Fontsへ通信せず端末の明朝体を使用します。

### 5.5 コンタクトフォーム表示調整

有効にするとbodyへ `sosc-contact-form` クラスを追加し、`.wpcf7-form` 内にフォーム調整用CSSを適用します。同じページの他のフォームには適用しません。この機能単独でも必要なJavaScriptを読み込みます。外部フォームプラグインのAPI連携ではなく、表示上の調整です。

### 5.6 Welcart店頭受取機能

Welcartの配送・支払画面をJavaScriptで調整します。

- 配送方法欄を「受け取り方法」と表示し、Welcartの選択肢から「店頭受け取り」を直接選択
- 配送先の選択欄と住所入力欄を支払い方法の下へ移動
- スマートフォン幅でもWelcartの2列の表を保ち、文字と選択操作を読みやすくする
- 配送先入力を非表示
- 到着希望日の名称を「お受け取り希望日」へ変更
- 到着希望時間の名称を「お受け取り時間」へ変更
- 日付候補から「指定しない」を除外
- 代引きを非表示
- 確認画面の配送先情報を非表示
- 通常配送へ戻した場合は表示を復元
- 店頭受取が選択済みの再表示でも表示を同期し、有効な支払方法の選択を保持

Welcart側に「店頭受け取り」という名称の配送方法が必要です。

### 5.7 Welcartサービス商品機能

配送を伴わないサービス商品の注文画面を調整します。

- 配送方法を「サービス商品」へ自動設定
- 配送先、配送方法、到着希望日、到着希望時間を非表示
- 代引きを非表示にして選択解除
- 利用可能な支払方法の先頭を選択
- カスタムオーダーフィールドを原則非表示
- `service_item_line` フィールドだけ表示
- 確認画面でも配送先と希望日時を非表示

「サービス商品」が存在し、同時に「店頭受け取り」が存在しない場合に実行されます。

## 6. SWELL向け表示機能

`.wp-block-media-text.sosc-reveal-media` を持つメディアとテキストブロックにスクロール連動アニメーションを適用します。

対象が画面内へ入ると `is-inview` クラスを追加します。ショートコードではなく、ブロックへ `sosc-reveal-media` クラスを指定して使用します。

## 7. 共通CSS・JavaScript

フロント画面では主に次の資産を読み込みます。

- スコープ化したBootstrap CSS
- 管理画面タブ用のローカルJavaScript
- jQuery
- ショートコード用CSS
- SWELL調整用CSS・JavaScript
- コンタクトフォーム調整用CSS
- その他機能用CSS・JavaScript

フロント資産は、投稿本文に `sosc_` ショートコードまたは `sosc-reveal-media` がある場合と、表示調整・Welcart連携設定が有効な場合だけローカルファイルから読み込みます。ウィジェットや独自テンプレートから動的に出力する場合は `sosc_force_front_assets` フィルターで有効化できます。JavaScriptはWordPress同梱jQueryをno-conflictのまま使用し、フッターで読み込みます。管理画面タブ、画像、CSS、JavaScriptはプラグイン内に同梱し、Bootstrap CDNや更新サーバー上の表示資産には依存しません。

## 8. 設定データ

プラグイン有効化時に次の独自テーブルを作成します。

```text
{WordPressのテーブル接頭辞}so_short_code
```

主な保存キーは次のとおりです。

| キー | 内容 |
| --- | --- |
| `h1_is_check` | H1非表示機能 |
| `contents_tm_is_check` | コンテンツ上マージン非表示 |
| `contents_bm_is_check` | コンテンツ下マージン非表示 |
| `font_change_select` | フォント指定 |
| `contact_form_is_check` | フォーム表示調整 |
| `welcart_pick_up_in_store_is_check` | Welcart店頭受取 |
| `welcart_service_item_store_is_check` | Welcartサービス商品 |

## 9. 独自更新機能

WordPress.orgではなく独自更新サーバーから更新情報を取得します。

```text
https://api.shonan-online.com/out_source/so-short-code.json
```

主な処理は次のとおりです。

- 更新JSONを取得して現在バージョンと比較
- 成功結果を30分間キャッシュ
- 通信・HTTP・JSONエラーを10分間キャッシュ
- WordPressのプラグイン一覧へ更新通知を追加
- 更新ZIPのURLをWordPressへ提供
- プラグイン詳細画面へ説明、導入方法、変更履歴、画像を提供

現行のプラグインヘッダー、`SOSC_VERSION`、更新JSONのバージョンはすべて `3.8.5` です。

## 10. 削除済みの旧実装

読込経路に含まれていなかったカウントダウン、画像切替、メニュー、アルコール販売警告・表記の旧実装は、安全性と動作を保証できないため削除しました。再導入する場合は新機能として実装・検証します。

## 11. 既知の制約と確認事項

現行コードの静的解析で確認した事項です。修正済みと判断せず、変更時の確認対象として扱ってください。

- 管理画面に掲載される15個のショートコードは、すべて実際の登録内容と一致します。
- `sosc_target_content` は対象LPが存在しない場合は空文字を返します。
- お知らせ・Welcart商品リストの `list` は1～100件へ正規化され、既定値は5件です。
- `sosc_target_content` は `the_content` フィルターを通し、通常本文と同じブロック、埋め込み、本文内ショートコード処理を適用します。
- No Image画像、プラグインアイコン、フロント用CSS・JavaScriptはプラグインへ同梱しています。更新サーバーへの依存は更新JSONと配布ZIPの取得だけです。
- Welcart購入画面の調整は、画面のID、name属性、日本語表示名を前提とするため、Welcart側の変更による影響を受けます。

## 12. 検証範囲

この文書はバージョン `3.8.5` のコードと自動テストを基準にしています。PHP 7.4/8.3の構文、WordPress 6.0.3/7.0.3での有効化、全ショートコード登録、代表出力、Welcart箱詰め計算、バックアップ暗号化を自動確認します。SWELLおよび正式対象ブラウザの最終的な外観は手動確認対象です。

機能変更時は [テスト仕様](../検証/移設前のテスト仕様_20260927.md) とルートの `AGENTS.md` に従って必要な検証を実施してください。
