[2026-10-20の現行基準画像](20261020-v3/)は、ローカルDockerのサンプルデータで確認した `so-short-code` の公開画面15ショートコードと管理画面3タブの表示を記録したものです。公開画面は320・390・768・1280pxの各幅でページ全体と部品ごとに撮影し、管理画面は320・390・1280pxで撮影しました。画像81枚、公開画面の[manifest](20261020-v3/manifest.json)、管理画面の[manifest](20261020-v3/admin-manifest.json)、[環境条件](20261020-v3/environment.json)を一体で保管します。

この基準は確認済みの**ローカル開発環境・固定サンプルデータ**の表示です。本番テーマ、実データ、別ブラウザの正解を主張するものではありません。公開画面は画像読込後にページ先頭へ戻して2秒待ち、撮影中だけテーマの `#pagetop` を非表示にします。スクロール遷移中に出る固定ボタンが比較結果を揺らしたためです。ショートコード領域は実表示のまま撮影します。管理画面の画像には当時のSWELL通知とWordPress管理バーも含まれるため、比較時はプラグイン領域の差分と分けて判断します。保存先識別子を表示する月次バックアップタブと、注文情報を扱う箱詰め画面はGit管理する画像に含めません。

[初版の基準画像](20261020/)も変更せず保存しています。初版にはスクロール遷移中のテーマ固定ボタンが写り、変更のない画面でも比較差分が出るため、通常の比較対象には使用しません。現行版は基準作成後に公開画面を2回、管理画面を1回独立再撮影し、合計81枚の差分0件を確認しました。
